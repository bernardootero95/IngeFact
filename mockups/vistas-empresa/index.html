Notas de este modelo

  • Reutiliza literalmente el mismo sidebar colapsable (con submenús "Documentos" y "Configuración") y la paleta de apps/user/tailwind.config.js, para que se pueda copiar el marcado/clases directo a los componentes React reales.
  • Se completaron algunos tonos intermedios de la paleta (brand-500/700, neutralCustom-200/300/400/600/700) que hoy no existen en el tailwind.config.js real pero sí se usan en clases del código (ej. hover:bg-brand-500, border-neutralCustom-200) — vale la pena agregarlos al config real para que esas clases sí generen estilo.
  • Datos de ejemplo ficticios — no hay conexión a Supabase ni a Alegra.
  • El sidebar es puramente visual: los enlaces navegan entre estos mismos archivos, no hay estado compartido entre páginas.
